# Partnerlogo's

Plaats hier de officiële logo's. Zodra een bestand bestaat, verschijnt het
automatisch op de pagina (in de logobalk onder de hero, in de sectie Partners en
in de footer). Zolang een bestand ontbreekt, toont de site een nette
tekst-wordmark als plaatshouder. Er hoeft niets in de code aangepast te worden.

## Verwachte basisnamen (exact, hoofdlettergevoelig)

De **basisnaam** moet exact kloppen; de **extensie** mag `.svg`, `.png`, `.webp`,
`.jpg` of `.jpeg` zijn (de site pikt automatisch het eerste bestaande bestand op,
in die volgorde van kwaliteit).

| Basisnaam         | Partner                                    |
|-------------------|--------------------------------------------|
| `whainot`         | WhaiNot                                    |
| `halle`           | Stad en OCMW Halle                         |
| `ucll`            | UCLL Research & Expertise                  |
| `vites`           | ViTeS                                      |
| `ommekaar`        | Buurthuis en sociale kruidenier Ommekaar   |
| `vlaamsbrabant`   | Provincie Vlaams-Brabant (financier, verplicht) |

## Richtlijnen

- Aanvaarde formaten, in volgorde van voorkeur: **`.svg`**, **`.png`**, **`.webp`**,
  **`.jpg`**, **`.jpeg`**.
- **SVG** of **PNG** met transparante achtergrond geeft het beste resultaat.
  **JPG** werkt ook: elk logo staat op een witte "chip", dus een witte
  JPG-achtergrond valt niet op en zwarte/kleurlogo's blijven leesbaar in zowel
  het lichte als het donkere thema.
- Het logo van de **provincie Vlaams-Brabant** is een verplicht element
  (hero-band + footer). Gebruik de officiële huisstijlversie.
