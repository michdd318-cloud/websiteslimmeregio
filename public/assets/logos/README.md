# Partnerlogo's

Plaats hier de officiële logo's als SVG. Zodra een bestand bestaat, verschijnt
het automatisch op de pagina (in de logobalk onder de hero, in de sectie
Partners en in de footer). Zolang een bestand ontbreekt, toont de site een nette
tekst-wordmark als plaatshouder. Er hoeft niets in de code aangepast te worden.

## Verwachte bestandsnamen (exact)

| Bestand              | Partner                          |
|----------------------|----------------------------------|
| `whainot.svg`        | WhaiNot                          |
| `halle.svg`          | Stad en OCMW Halle               |
| `ucll.svg`           | UCLL Research & Expertise        |
| `vites.svg`          | ViTeS                            |
| `ommekaar.svg`       | Buurthuis en sociale kruidenier Ommekaar |
| `vlaamsbrabant.svg`  | Provincie Vlaams-Brabant (financier, verplicht) |

## Richtlijnen

- Gebruik bij voorkeur **SVG** (schaalt scherp, licht van gewicht). PNG kan ook:
  pas dan de extensie aan in de `LogoSlot`-component (`src/components/primitives.tsx`,
  zoek op `.svg`).
- Lever logo's aan met **transparante achtergrond**.
- Houd de hoogte visueel in balans (de logobalk toont ze op ~34px hoog).
- Het logo van de **provincie Vlaams-Brabant** is een verplicht element
  (hero-band + footer). Gebruik de officiële huisstijlversie.
